# ✨ OrkoWallet – Grin 0.3.2 · The big update

The largest release so far, and the first one for **Linux**. Free, open source and made by the community, as always.

## Highlights

- 🐧 **Now on Linux**: `.deb`, `.rpm`, `.AppImage` and `.tar.gz` next to the Windows installer and the Android app. Same features everywhere.
- 🗂️ **One Settings window, eight clear categories**: General, Wallet, Security, Sending, Node, Backup, Maintenance and repair, About. The same on the desktop and the phone.
- 📴 **Slatepack only mode**: switch Tor off completely and pay with Slatepack texts (*Settings → General → Connection mode*).
- 📱 **A much better phone app**: every page scrolls to the end, pull down to refresh, a scroll button, big buttons in the node panel, and **Close wallet** right in the notification.
- 🔁 **Same wallet on two devices**: money spent on another device shows as *Spent on another device*; the change is found by a short scan, and a note explains how to use two devices safely.
- ⚡ **Instant Max** when sending.
- 🧹 **Tidy accounts**: remove an account from the list (only hidden, nothing is lost). Deleting a wallet stays a separate step with its own confirmation.
- 🔎 Kernel link on Android, rescan from this year by default, Android restarts by itself after a network change, and many more fixes.

Every detail is in the [changelog](https://github.com/orkorepo/orkowallet-grin/blob/main/CHANGELOG.md).

## Which file do I need?

| System | File |
|---|---|
| Windows 10 / 11 ✅ | `…-windows-x64-setup.exe` (installer) or `…-windows-x64-portable.zip` (no installation) |
| Debian, Ubuntu, Mint… 🧪 | `…-linux-amd64.deb` |
| Fedora, openSUSE… 🧪 | `…-linux-x86_64.rpm` |
| Any Linux 🧪 | `…-linux-x86_64.AppImage` or `…-linux-x86_64.tar.gz` |
| Android 7+ ✅ | `…-android-arm64.apk` |

**Check the download** against `SHA256SUMS.txt`: `Get-FileHash <file> -Algorithm SHA256` on Windows, `sha256sum <file>` on Linux.

**First start:** Windows may ask you to confirm the new installer (*More info → Run anyway*); compare the SHA-256 first.

> **Open to review.** The code is public and built on the official grin and grin-wallet libraries; an independent audit is still ahead of us and community reviews are very welcome. Keep your recovery phrase on paper.
