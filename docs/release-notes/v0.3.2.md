# ✨ OrkoWallet – Grin 0.3.2 · The big update

The largest release so far, and the first one for **Linux** and **macOS**. Free, open source and made by the community, as always.

## Highlights

- 🐧🍎 **Now on Linux and macOS**: `.deb`, `.AppImage` and `.dmg` (Apple Silicon and Intel) next to the Windows installer and the Android app. Same features everywhere.
- 🗂️ **One Settings window, eight clear categories**: General, Wallet, Security, Sending, Node, Backup, Maintenance and repair, About. The same on the desktop and the phone.
- 📴 **Slatepack only mode**: switch Tor off completely and pay with Slatepack texts (*Settings → General → Connection mode*).
- 📱 **A much better phone app**: every page scrolls to the end, pull down to refresh, a scroll button, big buttons in the node panel, and **Close wallet** right in the notification.
- 🔁 **Same wallet on two devices**: money spent on another device shows as *Spent on another device*; the change is found by a short scan, and a warning explains the risks.
- ⚡ **Instant Max** when sending.
- 🧹 **Tidy accounts**: remove an account from the list (only hidden, nothing is lost). Deleting a wallet stays a separate, clearly warned step.
- 🔎 Kernel link on Android, rescan from this year by default, Android restarts by itself after a network change, and many more fixes.

Every detail is in the [changelog](https://github.com/orkorepo/orkowallet-grin/blob/main/CHANGELOG.md).

## Which file do I need?

| System | File |
|---|---|
| Windows 10 / 11 ✅ | `…-windows-x64-setup.exe` (installer) or `…-windows-x64-portable.zip` (no installation) |
| Debian, Ubuntu, Mint… 🧪 | `…-linux-amd64.deb` |
| Fedora, openSUSE… 🧪 | `…-linux-x86_64.rpm` |
| Any Linux 🧪 | `…-linux-x86_64.AppImage` or `…-linux-x86_64.tar.gz` |
| Mac with Apple Silicon (M1 and newer) 🧪 | `…-macos-arm64.dmg` |
| Mac with Intel 🧪 | `…-macos-x64.dmg` |
| Android 7+ ✅ | `…-android-arm64.apk` |

**Check the download** against `SHA256SUMS.txt`: `Get-FileHash <file> -Algorithm SHA256` on Windows, `sha256sum <file>` on Linux, `shasum -a 256 <file>` on macOS.

**First start:** Windows may show SmartScreen (*More info → Run anyway*); the installer is not code-signed yet. macOS asks you to confirm because the app is not signed with a paid Apple Developer ID: *right-click → Open → Open*.

> This wallet has not had an independent security audit. Keep your recovery phrase on paper and use amounts you can afford to lose.
